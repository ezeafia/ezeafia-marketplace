# EZEAFIA BENBELLOS

A production-ready marketplace concept for Nigeria, built as a demo-first Next.js app.

## Stack
- Next.js 14
- TypeScript
- Tailwind CSS
- Demo data + mock services

## Local setup

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Demo features included
- Marketplace homepage
- Search + category navigation
- Product listing and detail pages
- Cart and checkout flow
- Seller and admin dashboards
- Notifications and trust centers
- Nigerian product data and pricing in Naira

## Notes
This is a demo-mode application designed for rapid iteration. Payment, delivery, and messaging flows are stubbed and clearly separated so they can be replaced later with real services such as Paystack, Flutterwave, or courier APIs.
